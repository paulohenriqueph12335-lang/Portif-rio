# Portif-rio_
Interactive business portfolio focused on Project Management, Business Intelligence, Data Analytics, Process Automation, and AI. Featuring real-world case studies, dashboards, and scalable solutions that transform complex challenges into measurable business results.


## Espaço de portfólio

Este repositório agora inclui uma landing page estática em `index.html`, com estilos em `styles.css`, para apresentar projetos, competências, indicadores e contato profissional.

---

## Publicação

O site é publicado direto pelo **GitHub Pages** (branch `main`, pasta raiz) e abre sempre a versão mais recente: não há modo offline nem nada para baixar.

- Fontes (Fraunces, IBM Plex Mono, Inter) ficam na raiz do projeto (`fonts.css` + arquivos `.woff2`), sem chamadas a CDNs externas.
- `tradutor.html` é a página do case Tradutor Documental, com a história do projeto e as telas do sistema (`tradutor-*.jpg`).
- `service-worker.js` só limpa a cópia offline de quem visitou o site quando ele ainda tinha esse modo.
